# Skyrim Alchemy

A app for _The Elder Scrolls_ - **Skyrim** to help navigate effects and ingredients effectively, to
quickly find effects for the ingredients you have and the ingredients for your desired effect.

All data for the app where sourced from [UESP Wiki - The Unofficial Elder Scrolls Pages - TES Wiki &
Lore](https://en.uesp.net/wiki/Main_Page), the best source for everything _The Elder Scrolls_!

This is a [Next.js](https://nextjs.org) project using [Bun](https://bun.sh) as package manager and
runtime.

Other libraries used:

- TypeScript
- TailwindCSS
- Shadcn
- Next Font
- Lucide icons

## Getting Started

First, install all dependencies:

```bash
bun install
```

Run the development server:

```bash
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You're ready to contribute!
